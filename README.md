# 💰 Tax Regime Calculator

A modern, intuitive web app that helps you **calculate and compare your income tax** under India's **Old vs New Tax Regimes** — with clarity, flexibility, and ease.

🔗 **Live App**: [https://tax-regime-calculator.netlify.app](https://tax-regime-calculator.netlify.app)

---

## 🧾 About the Project

This Tax Regime Calculator is built to simplify income tax planning for salaried individuals in India. Users can:

✅ Input their income structure  
✅ Add eligible deductions  
✅ Instantly compare tax liabilities under both regimes  
✅ Get recommendations for the most tax-efficient option

All within a responsive and beautifully designed interface.

---

- 🚀 Deployed on **Netlify**

```bash

cd income-tax-calculator

npm install

npm run start
```

## 🌟 Core Features

### 🏠 Landing Page

- Offers a clean and user-friendly introduction to the app.
- Instantly shows an overview of your total income and estimated tax liability.
- Encourages users to dive right into calculating and comparing tax regimes.

---

### 💼 Income Page

- Input income from various sources including salary, house rent, interest, and more.
- Dynamically adapts fields based on the selected income types.
- Gives real-time updates to keep your tax data accurate and responsive.

---

### 📉 Deduction Section

- Add deductions under key sections like **Rent Deduction**,**Section 24**, **Section 80C**, **Section 80D** and more.
- Handles exemption limits smartly to avoid over-claims.
- Automatically recalculates tax liabilities as you enter or adjust deductions.

---

### 📊 Tax Breakup

- Get a detailed, line-by-line tax breakdown under both **Old** and **New Tax Regimes**.
- Helps you understand how much you save or pay in each regime.
- Visual cues and suggestions to guide you toward the more tax-efficient option.
